Ansehen

Windows-Nutzer: Die Setup.exe ist der einfachste Weg — Hintergrund­dienst (kein Docker), ChromaDB embedded. Beim ersten Start zeigt Windows ggf. eine SmartScreen-Warnung („Weitere Informationen“ → „Trotzdem ausführen“), da der Installer nicht signiert ist — bei Open-Source normal. Für den Smartphone-Scan im LAN siehe Anleitung Smartphone-Scan.

Installation

Zwei Wege zum laufenden System.

Weg A — Quellpaket (empfohlen)

Baut die Images lokal und startet den kompletten Stack.

# Quellpaket entpacken
$ tar xzf zettelwirtschaft-1.8.0-source.tar.gz
$ cd zettelwirtschaft-1.8.0

# Konfiguration anlegen
$ cp .env.example .env

# Stack starten (baut Backend + Frontend)
$ docker compose up -d --build

# LLM-Modelle einmalig laden
$ docker compose exec ollama ollama pull gemma4:e2b-it-qat
$ docker compose exec ollama ollama pull qwen3-embedding:4b

Weg B — Vorgefertigte Images

Ohne lokalen Build — die geladenen Images direkt verwenden.

# Images laden
$ docker load -i zettelwirtschaft-backend-1.8.0-docker-image.tar.gz
$ docker load -i zettelwirtschaft-frontend-1.8.0-docker-image.tar.gz

# im entpackten Quellordner: Build durch Image ersetzen
# docker-compose.override.yml anlegen:
services:
  backend:
    build: !reset null
    image: zettelwirtschaft-backend:1.8.0
  frontend:
    build: !reset null
    image: zettelwirtschaft-frontend:1.8.0

$ docker compose up -d

Aufruf: Web-Oberfläche unter http://localhost:8080 · Health-Check http://localhost:8080/api/health. Hardware-Empfehlung: 8 GB RAM, ~10 GB Plattenplatz. Ausführliche Schritt-für-Schritt-Anleitungen stehen unter Anleitungen.
